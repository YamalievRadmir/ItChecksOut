# Заказы сайта → доставка

POST https://sklad.agro-korma-shop.ru/api/public/delivery-order
Content-Type: application/json
Авторизация и CSRF-токен для этого POST не требуются. Остальные маршруты сохраняют защиту.

Пример тела (название товара замените на точное название из склада):

```json
{
  "customerName": "Иван Петров",
  "phone": "+7 (900) 123-45-67",
  "address": "Екатеринбург, ул. Примерная, дом 10",
  "comment": "Позвонить перед приездом",
  "items": [
    {"productName": "Комбикорм ПК-1", "quantity": 2},
    {"productName": "Ракушка", "quantity": 1.5}
  ]
}
```

Сохраните JSON в order.json в UTF-8. Linux/macOS:

```bash
curl --fail-with-body -X POST 'http://localhost:8081/api/public/delivery-order' \
  -H 'Content-Type: application/json' \
  --data-binary @order.json
```

Windows PowerShell:

```powershell
curl.exe --fail-with-body -X POST "http://localhost:8081/api/public/delivery-order" -H "Content-Type: application/json" --data-binary "@order.json"
```

Для production замените http://localhost:8081 на https://sklad.agro-korma-shop.ru.
Каждый успешный POST создает реальную заявку. Повторный POST создает еще одну заявку.

Ответ HTTP 200:

```json
{"status":"success","message":"Заявка создана"}
```

Ошибочные поля/JSON: HTTP 400; конфликт сохранения: HTTP 409; неожиданный сбой: HTTP 500 без стектрейса в ответе.

Правила:
- Имя и адрес обязательны, до 255 символов. Телефон нормализуется до цифр (5–15 цифр); одинаковый нормализованный телефон использует существующего клиента.
- Комментарий до 4000 символов. От 1 до 100 позиций; название до 255 символов, количество положительное, максимум 99999999.99 и два знака после запятой.
- Название сопоставляется полностью без учета регистра, без нечеткого поиска. Дубли позиций объединяются.
- Неизвестные, неоднозначные названия и товары без корректной цены записываются в комментарий с количеством. Даже если все позиции неизвестны, заявка сохраняется для ручного уточнения; выполнение пустой заявки невозможно до добавления товаров.
- Завтра и 09:00 определяются часовым поясом JVM. Оплата по умолчанию «Нал», статус «Новая».
- Цена берется только из БД; создание не списывает и не резервирует остатки. Продавец проверяет доступность при обработке, списание — при ручном выполнении доставки.
- Новые имя и адрес всегда сохраняются в комментарии. Карточка существующего клиента не перезаписывается, чтобы не изменить предыдущие доставки; адрес конкретного заказа смотрите в комментарии.
- Создание фиксируется в AuditLog. Бейдж сегодня не включает завтрашнюю заявку: выберите «Завтра» в доставках.

CORS разрешен для https://agro-korma-shop.ru и https://www.agro-korma-shop.ru, метод POST. Пример браузерного вызова:

```javascript
const response = await fetch('https://sklad.agro-korma-shop.ru/api/public/delivery-order', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify(order)
});
const result = await response.json();
if (!response.ok) throw new Error(result.message);
```

Эндпоинт публичный: CORS не является защитой от ботов. На внешнем Nginx следует ограничить частоту запросов и размер тела; аутентификация для сайта по заданию не добавлена. Обработку формы сайта и ее CSP connect-src нужно настроить отдельно — сам сайт этим изменением не редактируется.
